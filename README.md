Technologies: Java 25, Maven, Spring Boot 3.5.7, Spring Web, Spring Data JPA, Lombok, Thymeleaf, HyperSQL Database, Spring Boot DevTools.
The Task List web app allows you to add a task that is assigned the "To Do" status. To complete the task, move it to the "IN_PROGRESS" status and then to the "Done" status.
